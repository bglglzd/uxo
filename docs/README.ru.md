# UXO

UXO — быстрое и приватное приложение для голосового ввода. Нажмите глобальную горячую клавишу, произнесите текст, и UXO локально распознает речь и вставит корректный Unicode-текст в активное приложение.

> [!WARNING]
> **v0.1.0 — предварительная неподписанная версия для Windows x64.** Windows SmartScreen может показать предупреждение «Неизвестный издатель». Скачивайте программу только из [официального релиза UXO](https://github.com/bglglzd/uxo/releases/tag/v0.1.0) и сверяйте файл с опубликованными [контрольными суммами SHA-256](https://github.com/bglglzd/uxo/releases/download/v0.1.0/SHA256SUMS.txt).

## Зачем нужен UXO

- **Оставляет видеокарту свободной.** Предварительная версия для Windows намеренно распознаёт речь только на CPU, поэтому диктовка остаётся доступной, пока игра или творческая программа полностью занимает GPU.
- **Выполняет обычную диктовку локально.** Звук с микрофона и основное распознавание остаются на компьютере; учётная запись облачного ASR-сервиса не нужна.
- **Не мешает работе.** После первоначальной настройки UXO может запускаться вместе с Windows, сразу скрываться и жить в системном трее.
- **Быстро реагирует.** Выбранная модель остаётся загруженной, а предварительный прогрев модели и VAD выполняется асинхронно после запуска.
- **Вставляет именно тот текст, который был произнесён.** UXO использует буфер обмена Windows и Unicode, а не эмуляцию зависящих от раскладки клавиш. Поэтому русский текст не превращается в бессмыслицу из латинских символов.
- **Подстраивается под сценарий.** Можно выбрать режим «удерживать для записи» или переключение записи, настроить микрофон и язык, а также использовать Nemotron, Whisper, Parakeet и другие совместимые локальные модели.

## Быстрый старт

1. **[Скачайте UXO v0.1.0 для Windows x64](https://github.com/bglglzd/uxo/releases/download/v0.1.0/UXO_0.1.0_x64-setup.exe).** MSI-пакет также доступен на [странице релиза](https://github.com/bglglzd/uxo/releases/tag/v0.1.0).
2. Запустите установщик. Поскольку эта Preview-версия не подписана кодовой подписью, Windows может попросить подтвердить запуск от неизвестного издателя.
3. Пройдите первоначальную настройку и загрузите модель распознавания. Модели не входят в установщик.
4. Поставьте курсор в любое текстовое поле, нажмите настроенную горячую клавишу и говорите.

Для нового профиля после онбординга по умолчанию включены запуск вместе с Windows и скрытый старт. Горячая клавиша, режим push-to-talk, автозапуск, микрофон, модель, язык распознавания, звуки, история и способ вставки настраиваются в интерфейсе UXO.

## Локальный конвейер

```text
глобальная клавиша → микрофон → удаление тишины → локальное ASR → вставка Unicode
```

В основном сценарии UXO не отправляет звук с микрофона сервису распознавания речи. После загрузки выбранной модели обычная диктовка может работать без подключения к интернету.

## Модели и языки

Рекомендуемая модель для Windows — Q8 GGUF-версия [NVIDIA Nemotron 3.5 ASR Streaming 0.6B](https://huggingface.co/nvidia/nemotron-3.5-asr-streaming-0.6b). Она занимает примерно **751 МБ**, загружается отдельно во время настройки и не включена в установщик. Модель поддерживает потоковое распознавание с кешированием и даёт удачный для этой версии баланс между скоростью отклика, многоязычностью и нагрузкой на CPU.

Также доступны модели семейства Whisper и другие локальные варианты с иными компромиссами по точности, языкам, памяти и задержке. Языки распознавания определяются выбранной моделью и не совпадают с перечнем языков интерфейса UXO.

### Распознавание речи

Рекомендуемая модель Nemotron готова к работе без дополнительного обучения с **32 локалями на базе 28 языков**:

английского, испанского, французского, итальянского, португальского, нидерландского, немецкого, турецкого, русского, арабского, хинди, японского, корейского, вьетнамского, украинского, польского, шведского, чешского, норвежского букмола, датского, болгарского, финского, хорватского, словацкого, китайского путунхуа, венгерского, румынского и эстонского.

Для английского, испанского, французского и португальского доступны несколько региональных локалей, поэтому 28 базовых языков образуют 32 локали. Качество зависит от языка, акцента, микрофона и акустики; у других моделей из каталога свой набор поддерживаемых языков.

## Граница приватности

По умолчанию запись и распознавание выполняются локально, но важно точно понимать границы приватности:

- Для первоначальной и последующих загрузок моделей нужно подключение к сети; файлы скачиваются с соответствующих хостингов моделей.
- История и сохранённые аудиозаписи могут записываться на локальный диск в соответствии с настройками пользователя.
- Постобработка с помощью LLM — отдельная необязательная функция. Если пользователь её настроил и вызвал, текст расшифровки отправляется выбранному внешнему провайдеру на его условиях. Эта функция не относится к локальной и офлайн-гарантии UXO.
- В этой Preview-версии адреса провайдеров и API-ключи сохраняются в локальных настройках приложения открытым текстом, а не в специальном системном хранилище учётных данных. Используйте ключи с минимальными правами и возможностью отзыва; не настраивайте внешнюю постобработку в недоверенной общей учётной записи Windows.

## Управление из командной строки

Обычно UXO управляется через трей и глобальную горячую клавишу, но интерфейс командной строки для единственного экземпляра удобен для скриптов и лаунчеров:

```text
uxo --start-hidden
uxo --toggle-transcription
uxo --toggle-post-process
uxo --cancel
uxo --debug
```

Параметры командной строки действуют только во время запуска и не изменяют сохранённые настройки.

## Сборка из исходного кода

Необходимы:

- последняя стабильная версия [Rust](https://rustup.rs/);
- [Bun](https://bun.sh/);
- Visual Studio C++ Build Tools и Windows SDK;
- CMake и Ninja для нативных зависимостей распознавания.

Установите зависимости фронтенда. Модель VAD для разработки уже хранится в репозитории по пути `src-tauri/resources/models/silero_vad_v4.onnx`:

```powershell
bun install
```

Запустите проверки:

```powershell
bun run build
bun run lint
bun run check:translations
bun run format:check
cargo test --manifest-path src-tauri/Cargo.toml --lib
```

Для нативной сборки под Windows нужна проверенная среда MSVC, Visual Studio CMake и Ninja, описанная в [BUILD.md](../BUILD.md). В частности, убедитесь, что посторонняя версия MinGW CMake не оказалась раньше нужной в `PATH`.

## Границы Preview-версии

- Готовый релиз сейчас предназначен для **Windows x64**. Пути разработки для macOS и Linux существуют, но эти системы не являются проверенными целями релиза UXO v0.1.0.
- В этой Preview-версии распознавание под Windows намеренно работает только на CPU. Ускорение на GPU в будущем может вернуться как явно включаемый режим.
- Установщик не подписан кодовой подписью; подписанного стабильного канала обновлений пока нет.
- Качество зависит от языка, а текущие заметки о производительности не заменяют широкого тестирования точности в реальных условиях.
- Для необязательной внешней постобработки действуют описанные выше ограничения приватности и хранения локальных секретов.

Воспроизводимые проблемы UXO можно сообщать в [трекере проекта](https://github.com/bglglzd/uxo/issues). Инструкции для разработчиков находятся в [CONTRIBUTING.md](../CONTRIBUTING.md).
