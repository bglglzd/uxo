# Built-in term dictionary for post-transcription correction.
#
# Format: Canonical = alias | alias | ...
# - Matching ignores case, punctuation inside a word, and ё/е differences;
#   aliases may span up to four words ("чат джипити").
# - The canonical spelling also matches itself when its casing is distinctive
#   (GitHub, iPhone, Node.js, API), which fixes "github" -> "GitHub". Plainly
#   capitalized names (Word, Teams, Apple) never match the ordinary word.
# - Only add aliases that are NOT ordinary words in any language UXO supports.
#   "питон" (snake), "телеграмма" (a telegram), "курсор", "зум", "кафка",
#   "react", "swift", "word", "excel" and similar are deliberately absent.
